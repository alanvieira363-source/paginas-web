# Ochava · web de demostración para un bar

Propuesta de ejemplo para mostrarle a un bar cómo podría ser su web propia.
"Ochava" es un bar ficticio: dirección, teléfono, precios y reseñas son de muestra.

- **Inicio:** portada animada (la esquina de noche: tocá las ventanas, activá o desactivá la llovizna), estado abierto/cerrado en vivo, agenda de la semana, la casa, tragos destacados y reseñas de ejemplo.
- **Carta:** categorías, buscador, filtros (sin alcohol, veggie, sin TACC…), ficha de cada producto y recomendador de tragos.
- **Reservas:** personas, calendario, horarios con disponibilidad, plano del bar para elegir zona, datos y ticket de confirmación.
- **Contacto:** mapa esquemático, horarios, datos para copiar, formulario y preguntas frecuentes.

Para verla: abrí `index.html` en el navegador. Es un solo archivo HTML con las imágenes en `img/`, sin dependencias salvo Google Fonts.
